# 🌌 Вселенная паркура (Parkour Universe)

Динамичный 2D платформер с акробатикой, паркуром, босс-битвами и процедурной неоновой графикой!

## 🎮 Играть прямо сейчас
👉 **[Запустить «Вселенную паркура» онлайн](https://igorzu117-design.github.io/parkour-universe/)**

## 🕹️ Управление
- **A / D** или **Стрелки ← / →** — Движение влево / вправо
- **Shift** — Рывок (Dash) вперед
- **Ctrl + Shift** — Кувырок / Слайд под низкими препятствиями
- **Ctrl** — Присесть / Проползти
- **Пробел** — Прыжок / Двойной прыжок в воздухе
- **E** — Карабкаться по лестнице
- **Канат / Лиана** — Раскачивание на **A / D**, отталкивание на **Пробел**
- **Esc** — Меню паузы

## ✨ Особенности игры
- Плавная физика прыжков, скольжения по стенам и инерции
- Разнообразные уровни с ловушками, лазерами, батутами и платформами
- Битва с роботом-боссом
- Процедурный саундтрек и звуковые эффекты на Web Audio API
- Стильный интерфейс с эффектом Glassmorphism
